# 🗼 French Voyage

A French A1–A2 learning platform: grammar lessons, spaced-repetition flashcards,
a verb conjugation engine, quizzes, dialogues, and speech practice — offline-first,
built with React + Vite, with an optional Express + SQLite sync API.

> 🚧 Being rebuilt from the ground up as a learning journey — follow the tags
> (`v0.01` → `v1.0.0`) to watch it grow.

## Planned features

- 62 grammar lessons (A1–A2), 669 vocabulary cards, 80 fully conjugated verbs
- SM-2 spaced-repetition trainer
- Rule-based conjugation engine (7 tenses + imperative)
- Quizzes with accent-tolerant answer checking
- Speaking practice via the Web Speech API
- Progress dashboard with charts
- Optional account sync (Express + node:sqlite + JWT)

## Tech stack

React 18 · Vite · Bootstrap 5 · Sass · Chart.js · Express · node:sqlite · Vitest
